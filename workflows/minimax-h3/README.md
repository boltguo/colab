# MiniMax H3 视频工作流

| 工作流 | 怎么使用 | 视频比例 |
| --- | --- | --- |
| [01 · 文生视频](01_MiniMaxH3_T2V_A100_80GB.json) | 写提示词，选择比例后运行 | 手动选择 |
| [02 · 首帧图生视频](02_MiniMaxH3_I2V_A100_80GB.json) | 上传首帧，描述动作后运行 | 自动跟随首帧 |
| [03 · 首尾帧视频](03_MiniMaxH3_FirstLast_A100_80GB.json) | 上传首帧和尾帧，描述中间动作后运行 | 自动跟随首帧 |
| [04 · 双图参考视频](04_MiniMaxH3_R2V_A100_80GB.json) | 上传两张参考图，用 `<Picture 1>` / `<Picture 2>` 对应图片后运行 | 默认跟随参考图 1 |

1. 按 [A100 80GB 笔记本](../../notebooks/minimax-h3/MiniMaxH3_A100_80GB.ipynb) 顺序运行，自动准备模型和工作流。
2. 在 ComfyUI 打开对应工作流，或直接拖入 JSON。修改中文提示词；有图片输入时先上传并选择图片。
3. 点击运行，完成后在“保存视频与声音”节点查看，或用笔记本第 4 区下载。

默认 **5 秒、20 步、基础模式**。需要其他时长时修改“时长（秒）”。图片版自动按参考图比例缩放，不用填写宽高；“清晰度”一般保持默认即可。首尾帧建议使用相同比例的图片。

04 当前提供两张图片上传入口，使用 `<Picture 1>` / `<Picture 2>` 对应图片。尚未提供音频、视频上传入口。使用 04 需在下载格启用 `DOWNLOAD_R2V`。加速模式需先下载对应权重。

全部使用 ComfyUI 内置节点。示例图片需替换为自己的图片。工作流沿用 Comfy Org 的 MIT 许可，完整许可保留在 JSON 中。
