# 五个工作台审查与改进

审查日期：2026-11-15。基础提交：`d595c31`。

本轮保留原有五个独立工作台、模型版本、引擎选择与亮色视觉体系。重点修复参数语义、输入到结果的流程和日常使用中的状态问题。

## 逐项结论

| 工作台 | 主要问题 | 本轮改进 |
| --- | --- | --- |
| Qwen-Image 2.1 | 空参考槽被过滤后，屏幕编号与模型收到的 `<imageN>` 不一致；原图尺寸转自定义组合冲突；历史恢复遗漏种子和旧参考图清理 | 前后端检查参考图顺序；统一尺寸切换；回填实际种子、参考图和负提示词状态 |

| SeedVR2 | 裁剪后对比仍从原片 0 秒开始；变速保留原声导致错位；无效媒体回退成虚构元数据；目标尺寸与节点不一致 | 同步裁剪起点、帧率比和裁切方式；明确变速与原声互斥；验证真实媒体与输出尺寸；处理手机竖拍的旋转元数据 |
| IndexTTS 2.5 | 模型释放可打断推理；切换引擎配置累积模型；Top-K=0 映射不一致；字幕估算被描述为精确时间轴 | 推理与释放互斥、仅驻留一套配置；正确透传 Top-K=0；加载后设种子；保持输出采样率；标明估算字幕并修复时间进位 |
| Qwen3.8-27B | 工具 JSON 无效时先清空草稿；流断开被当作正常结束；停止后内部连接未完全关闭；API 示例缺少部分配置 | 发送前校验并保留输入；区分完成、截断、错误和手动停止；清理内部流；同步全部页面采样参数、附件、JSON 与工具配置 |

## 公共流程

1. **进入工作台**：保留同源服务和 API Key 入口；修复开发构建目录识别。窄屏提供参数/结果快速跳转，长侧栏可独立滚动。
2. **选择素材**：提前提示不支持的格式、空文件和大小限制；避免重复上传；录音离开组件时停止麦克风；异步加载的内置音色与当前选择保持一致。
3. **调节参数**：IndexTTS 核心参数按分组直接展示，底层引擎仍折叠；无效模式与音轨/FPS 组合给出具体说明。
4. **生成与取消**：同步保护重复提交；取消排队与 worker 领取任务使用同一把锁；轮询避免重叠和重复报错；卸载页面不继续订阅任务。
5. **查看与复用结果**：历史从当前服务的真实任务恢复，避免沿用已销毁实例的浏览器记录；清空列表涵盖当前服务已读取的全部历史；回填使用实际种子。

## 启动与发布

- 启动指纹包含应用包版本、API Key 摘要和服务环境参数，更新应用或更换密钥会重启服务。
- 依赖媒体处理的工作台在启动前检查 FFmpeg/ffprobe，并给出缺失时的处理方式。
- Release 只接受新版本号，禁止覆盖既有文件；笔记本继续由模板生成。
- 本分支保留现有 `v0.1.0` 包的真实哈希。合并并发布新版本后，新代码才会进入 Colab 的安装流程。

## 验证与边界

- 五个前端 TypeScript 检查与生产构建。
- 67 项 Python 回归测试：模型适配、任务竞争、启动指纹、发布保护以及五个工具的 Mock API 完整流程。
- 14 项 Node 原生测试：SSE 网络分块、取消、参数导出、工具预览上下文和原图尺寸转自定义。
- 使用真实小媒体文件验证 FFmpeg 的帧率、音轨、裁剪、旋转和采样率行为。
- 五份生成后的笔记本检查 Python 语法和模板可重复生成；检查每个应用包包含对应前端和独立后端。

本轮没有加载 GPU 权重做完整推理，未验证真实模型质量、吞吐和 40GB 显卡下的最大上下文。浏览器无法访问当前隔离环境中的本地服务端口，因而未完成实屏截图与响应式视觉验收；布局改动已做源码与构建检查。

IndexTTS 主权重沿用固定 revision，但官方初始化还会下载部分辅助模型。完整辅助权重清单的锁定不在这次适度优化范围内。
